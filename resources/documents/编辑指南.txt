## ✏️ 怎么改内容

### 1. 改一道题的答案
打开对应的 HTML 文件（用记事本/VSCode/任何文本编辑器），搜索题目关键词找到对应位置，直接改文字即可。

### 2. 添加一道新题
每道题的结构如下（找到任意一道题复制这段，改数字和内容）：


### 3. 颜色标签说明

| 标签 | class | 适合什么题型 |
|------|-------|------------|
| 蓝 | `tag-b` | 极限、导数、微分、积分、全微分 |
| 紫 | `tag-p` | 方程、不等式、级数 |
| 粉 | `tag-pk` | 向量、空间几何、二次曲面 |
| 绿 | `tag-g` | 概率、级数审敛 |
| 橙 | `tag-o` | 应用题 |

题的左边框和题号颜色：改 `style="border-left-color:var(--blue)"` 和 `style="background:var(--blue);"` 中的颜色名即可。

### 4. 加一张新试卷
1. 复制一份已有的试卷 HTML 文件
2. 改文件名、标题、题目内容
3. 在 `index.html` 里加新卡片

## 🌐 怎么发布（上传到网站）

改完 HTML 后，在文件夹里右键 → Git Bash Here，运行：

```bash
# 先看看改了什么
git status

# 添加所有改动
git add .

# 提交（写清楚改了什么）
git commit -m "修改了什么内容"

# 推到GitHub
git -c http.sslBackend=schannel push origin main

# 推到Gitee（国内镜像）
git -c http.sslBackend=schannel push gitee main
```

如果 GitHub 推送报 SSL 错误，把 `schannel` 换成 `openssl` 重试。

推送完等 1 分钟左右，网站就自动更新了。

## 🎨 其他小技巧

- **数学公式**：尽量用 Unicode（∫ ∬ ∂ ∇ √ ∑ ∏ ∞ 等）
- **上标下标**：`<sup>上标</sup>` `<sub>下标</sub>`
- **根号**：`<span class="sqrt"><span class="sqrt-inner">表达式</span></span>`
- **积分上下限**：用内置的 `.intl` 类（参考现有题目里的写法）
- **保留备份**：改之前把原文件复制一份，改坏了能恢复
