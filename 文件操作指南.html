📂 文件打开 — open() 函数

Python 通过内置的 open() 函数打开文件，返回一个文件对象，所有后续操作都通过这个对象进行。

基本语法： open(file, mode='r', encoding=None)

file文件路径（字符串）
mode打开模式（见下表）
encoding编码方式，推荐 'utf-8'

打开模式速查：

模式含义文件不存在时文件存在时
'r'只读（默认）❌ 报错✅ 从头读
'w'覆盖写✅ 创建新文件⚠️ 清空后写
'a'追加写✅ 创建新文件✅ 末尾追加
'x'独占创建✅ 创建新文件❌ 报错
'r+'读写❌ 报错✅ 从头读写
'b'二进制模式配合以上模式使用，如 'rb' 'wb'
示例：创建文件并写入open('hello.txt', 'w') 创建或覆盖文件

📖 读取文件的四种方式

方法行为返回值
.read()读取全部内容字符串
.read(n)读取 n 个字符字符串
.readline()读取一行（含 \n）字符串
.readlines()读取所有行列表（每行一个元素）
for line in f:逐行迭代每次一行（推荐！省内存）

处理大文件时，用 for line in f 逐行读取，避免一次性加载到内存。

✏️ 写入文件的方法

方法行为
.write(s)写入字符串 s，返回写入的字符数
.writelines(seq)写入字符串序列，不会自动加换行符

⚠️ 注意：writelines() 不会自动在元素间加换行符！如果需要每行换行，要自己加上 \n。

两种写模式的区别：

模式指针位置行为
'w'文件开头先清空，再写入
'a'文件末尾追加写入，不清空

🔄 with 语句 — 更安全的文件操作

强烈推荐！使用 with 语句打开文件，退出代码块时自动调用 close()，即使发生异常也不会忘记关闭。

传统写法with 语句
f = open('a.txt', 'r')
data = f.read()
f.close() ← 容易忘！		 with open('a.txt', 'r') as f:
    data = f.read()
# 自动关闭 ✓

with 语句基于 Python 的上下文管理器协议：进入时调用 __enter__()，退出时调用 __exit__()（自动 close）。

📍 文件指针 — seek() 和 tell()

文件对象维护一个当前位置指针，指示下一次读写从哪里开始。

方法功能
.tell()返回当前指针位置（字节偏移）
.seek(offset, whence)移动指针到指定位置

seek 的 whence 参数：

whence含义
0从文件开头（默认）
1从当前位置
2从文件末尾

中文 UTF-8 编码下，一个汉字占 3 字节。seek 按字节移动，跳转到汉字中间可能导致乱码！
